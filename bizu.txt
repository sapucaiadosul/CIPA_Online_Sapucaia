Entrar na pasta do sistema:
> cd /var/www/html/sistema_cipa

Ver se o Apache está ativo:
> sudo systemctl status apache2

Se estiver OK, aparecerá algo assim: Active: active (running)

Ver se o MySQL está ativo
> sudo systemctl status mysql

Se estiver OK: Active: active (running)

Reiniciar Apache
> sudo systemctl restart apache2

Reiniciar MySQL
> sudo systemctl restart mysql

Reiniciar os dois juntos
> sudo systemctl restart apache2 mysql

Ver logs do Apache - Muito útil quando dá erro 500:
> sudo tail -f /var/log/apache2/error.log

Ver logs do Laravel
> tail -f storage/logs/laravel.log    ou 
> tail -f storage/logs/*.log

Ver se a porta 80 está aberta
> sudo ss -tulpn | grep :80
Se Apache estiver rodando: LISTEN

Ver se MySQL está ouvindo na 3306
> sudo ss -tulpn | grep :3306
